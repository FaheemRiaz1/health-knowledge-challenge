# Test Checklist

Record the date and result of each test before presenting the project as completed.

## Single-player functionality

- [ ] The experience starts without red errors in the Output window.
- [ ] The generated world contains three labelled stations.
- [ ] The player spawns in the central plaza.
- [ ] Each station displays a proximity prompt.
- [ ] A question opens after interacting with a station.
- [ ] Four answer options appear and can be selected.
- [ ] Correct answers add 10 Knowledge points.
- [ ] Correct answers increase the Correct statistic.
- [ ] Wrong answers show the correct option and an explanation.
- [ ] The timer submits an expired answer after 15 seconds.
- [ ] Five correct answers complete the challenge.
- [ ] The 50-point completion bonus is awarded only once.

## Multiplayer functionality

- [ ] Start a local server with at least two players.
- [ ] Both players can open different questions independently.
- [ ] One player's answer does not change another player's active question.
- [ ] Each player has independent Knowledge and Correct statistics.
- [ ] A completion announcement is shown to all connected players.

## Usability review

- [ ] Text is readable at desktop resolution.
- [ ] UI remains usable in Roblox Studio mobile emulation.
- [ ] Questions and feedback are understandable.
- [ ] The player understands where to go without verbal instructions.
- [ ] At least one other person tests the prototype and gives feedback.

## Evidence for portfolio

- [ ] Add two or more screenshots to the repository.
- [ ] Record a 30–60 second demonstration.
- [ ] Add a short testing note describing one issue found and fixed.
